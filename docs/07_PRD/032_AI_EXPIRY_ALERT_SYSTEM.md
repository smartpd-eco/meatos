# 1. 프로젝트 목적

축산물이력제(Open API)의 도축일자를 기준으로
품목별 / 부위별 / 보관방법별 권장 유통기한을 자동 계산하여

정육점에서

- 유통기한 임박
- 유통기한 만료
- 오늘 확인해야 할 품목

을 자동으로 알려주는 AI 알림 시스템을 구축한다.

MEATOS ERP의 핵심 경쟁 기능으로 사용한다.

# 4. 정부 자료 조사

## 참고기관

식품의약품안전처

축산물품질평가원

농림축산식품부

축산물위생관리법

식품 등의 표시기준

축산물 보관기준

※ 정부에서는 "부위별 유통기한"을 법으로 고정하지 않는다.

유통기한은

제품 특성

포장방법

보관온도

미생물 시험

등을 종합하여 제조자가 설정한다.

따라서

MEATOS에서는

실무 권장 기준(Default)을 사용하며

관리자가 수정 가능하도록 설계한다.
