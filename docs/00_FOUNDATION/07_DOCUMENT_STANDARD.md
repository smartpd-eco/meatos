# 07_DOCUMENT_STANDARD.md

# MEATOS Document Standard

**Version**: 1.0\
**Author**: SmartPD\
**Status**: Active\
**Last Update**: 2026-07-10

------------------------------------------------------------------------

# 1. 목적

본 문서는 MEATOS 프로젝트에서 작성되는 모든 문서의 형식과 관리 기준을
정의한다.

문서는 개발보다 먼저 작성하며 프로젝트의 기준이 된다.

------------------------------------------------------------------------

# 2. 문서 우선순위

1.  Foundation
2.  Project
3.  Architecture
4.  PRD
5.  Sprint
6.  Code

상위 문서가 항상 우선한다.

------------------------------------------------------------------------

# 3. 모든 문서 Header

모든 문서는 아래 정보를 포함한다.

-   Title
-   Version
-   Author
-   Status
-   Last Update
-   Related Documents (필요 시)

------------------------------------------------------------------------

# 4. 문서 작성 원칙

-   한 문서에는 하나의 주제만 담는다.
-   읽는 사람이 5분 안에 이해할 수 있도록 작성한다.
-   코드보다 업무 흐름을 먼저 설명한다.
-   그림보다 업무 순서를 우선 설명한다.

------------------------------------------------------------------------

# 5. 문서 네이밍

Foundation

01_MEATOS_CONSTITUTION.md

02_PROJECT_VISION.md

...

숫자로 관리하여 항상 같은 순서로 읽을 수 있도록 한다.

------------------------------------------------------------------------

# 6. 문서 수정

-   Version을 갱신한다.
-   변경 이유를 Commit 메시지에 남긴다.
-   큰 변경은 PM 검토 후 반영한다.

------------------------------------------------------------------------

# 7. 문서와 코드

문서와 코드가 다르면 문서를 먼저 수정한다.

문서 없는 기능은 개발하지 않는다.

------------------------------------------------------------------------

# 8. AI 문서 작성 규칙

AI는 새로운 기능을 만들기 전에

-   기존 문서 확인
-   중복 여부 확인
-   관련 문서 수정

을 먼저 수행한다.

------------------------------------------------------------------------

------------------------------------------------------------------------

# 11. 우리의 약속

좋은 문서는 좋은 개발을 만든다.

좋은 개발은 좋은 제품을 만든다.

우리는 문서를 프로젝트의 자산으로 관리한다.
