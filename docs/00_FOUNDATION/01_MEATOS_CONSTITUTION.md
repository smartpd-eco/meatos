**Last Update**: 2026-07-10

> **이 문서는 완벽함을 목표로 하지 않는다.**
>
> **프로젝트와 함께 성장하는 살아있는 기준이다.**

------------------------------------------------------------------------

# 전문(Preamble)

MEATOS는 단순한 프로그램을 만드는 프로젝트가 아니다.

우리는 정육점, 식당, 축산물 유통업체의 반복 업무를 줄이고, 사람이 더
중요한 일에 집중할 수 있도록 돕는 AI 기반 운영 플랫폼을 만든다.

이 헌법은 모든 설계, 개발, 문서, AI의 최상위 기준이다.

------------------------------------------------------------------------

# 제1조. 존재 이유

우리는 기능을 많이 만드는 것이 목표가 아니다.

현장의 시간을 아껴주는 것이 우리의 존재 이유이다.

------------------------------------------------------------------------

# 제2조. 고객 우선

모든 판단의 기준은 개발자가 아니라 현장 사용자이다.

"사장님이 더 쉽게 사용할 수 있는가?"를 항상 먼저 생각한다.

------------------------------------------------------------------------

# 제3조. 문서 우선

모든 개발은 문서에서 시작한다.

Idea → Document → Architecture → Code

문서 없는 개발은 하지 않는다.

------------------------------------------------------------------------

# 제4조. Engine First

MEATOS는 Engine 중심으로 설계한다.

Core Engine은 쉽게 변경하지 않는다.

UI와 Plugin은 언제든 발전할 수 있다.

------------------------------------------------------------------------

# 제5조. Inventory First

모든 재고의 생성과 변경은 Inventory Engine을 기준으로 한다.

재고를 우회하는 기능은 만들지 않는다.

------------------------------------------------------------------------

# 제6조. AI의 역할

AI는 추천하고 분석한다.

최종 결정은 항상 사람이 내린다.

------------------------------------------------------------------------

# 제7조. 플랫폼 철학

우리는 POS를 대체하지 않는다.

우리는 모든 POS와 연결되는 플랫폼을 만든다.

정부 정책은 활용하지만 정부에 종속되지 않는다.

------------------------------------------------------------------------

# 제8조. 성장의 원칙

완벽하게 시작하지 않는다.

하나씩, 꾸준히, 완성해 나간다.

좋은 아이디어는 PM Journal에 기록하고, 충분히 검토된 후 헌법에 반영한다.

------------------------------------------------------------------------

# 제9조. 헌법 개정

이 문서는 변경 금지 문서가 아니다.

다만 변경은 반드시

1.  PM 검토
2.  프로젝트 방향 확인
3.  Version 상승
4.  변경 이력 기록

을 거쳐 반영한다.

------------------------------------------------------------------------

# 제10조. 우리의 약속

우리는 ERP를 만드는 것이 아니다.

우리는 POS를 만드는 것이 아니다.

우리는 축산 유통의 새로운 표준을 만든다.
