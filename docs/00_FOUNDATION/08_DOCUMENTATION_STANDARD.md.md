# MEATOS Documentation Standard v1.0

> Documentation Driven Development (DDD)

## 목적

MEATOS 프로젝트의 문서 체계와 작성 표준을 정의한다.

## 문서 우선순위

1.  MEATOS_CONSTITUTION
2.  PROJECT_VISION
3.  PROJECT_RULES
4.  ARCHITECTURE
5.  PRD
6.  SPRINT
7.  CODE

## 디렉터리 구조

``` text
docs/
├──00_FOUNDATION
├──01_PROJECT
├──02_ARCHITECTURE
├──03_DATABASE
├──04_API
├──05_AI
├──06_UIUX
├──07_PRD
├──08_SPRINT
├──09_TEST
├──10_RELEASE
└──99_HISTORY
```

## 작성 원칙

-   Engine First
-   Inventory First
-   Event First
-   Documentation First
-   POS = Plugin
-   AI = Recommendation Only

## 문서 Header

-   Title
-   Version
-   Author
-   Status
-   Related Docs
-   Last Update

## 개발 순서

Idea → Document → Architecture → Database → API → UI → Code → Test →
Release

## 최종 선언

MEATOS는 프로그램이 아니라 플랫폼이며, 대한민국 축산 유통의 Operating
System을 목표로 한다.
