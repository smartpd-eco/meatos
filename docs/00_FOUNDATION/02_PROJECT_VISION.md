# 1. 프로젝트 소개

MEATOS는 정육점, 식당, 축산물 유통업체를 위한 AI 기반 SCM(Supply Chain
Management) 플랫폼이다.

거래명세서 OCR, 상품명 표준화(Alias), 재고관리, 발주관리, POS 연동,
축산물이력관리까지 하나의 플랫폼에서 운영하는 것을 목표로 한다.

------------------------------------------------------------------------

# 2. 왜 MEATOS를 만드는가?

현재 대부분의 정육점은 다음과 같은 문제를 가지고 있다.

-   거래명세서를 수기로 입력한다.
-   공급업체마다 상품명이 모두 다르다.
-   재고가 정확하지 않다.
-   POS와 재고가 연결되지 않는다.
-   발주는 경험에 의존한다.
-   축산물이력 조회가 번거롭다.

MEATOS는 이러한 반복 업무를 줄여 사장님이 장사에 집중할 수 있도록
돕는다.

# 4. 우리의 방향

-   POS를 대체하지 않는다.
-   ERP를 복잡하게 만들지 않는다.
-   현장의 업무를 단순하고 정확하게 만든다.
-   실제 사용하는 기능부터 개발한다.

------------------------------------------------------------------------

# 5. 핵심 가치

-   **Simple** : 누구나 쉽게 사용
-   **Accurate** : 재고는 항상 정확하게
-   **Connected** : 모든 데이터는 연결
-   **Practical** : 현장에서 필요한 기능 우선
