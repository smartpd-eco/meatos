# MEATOS Documentation Governance

Version: 1.0
Status: Active
Date: 2026-07-11

---

# 목적

문서가 많아질수록 같은 내용을 반복하지 않는다.

새로운 MD는 기존 문서를 확장하거나 참조하며,
중복을 최소화한다.

---

# 문서 작성 원칙

1. 하나의 문서는 하나의 책임만 가진다.
2. 기존 문서에 있는 내용을 복사하지 않는다.
3. 필요한 경우 링크(참조)만 추가한다.
4. 변경 사항만 기록한다.
5. Sprint 종료 후 문서를 정리한다.

---

---

# 중복 방지 체크리스트

새 문서를 만들기 전에 반드시 확인한다.

□ 같은 목적의 문서가 있는가?

□ 기존 문서를 수정하면 해결되는가?

□ 정말 새로운 책임을 가지는 문서인가?

세 가지 모두 통과해야 새 문서를 만든다.

---

# 앞으로 Peter 규칙

새 MD 생성 전

1. 기존 MD와 역할 비교
2. 중복 여부 검토
3. 기존 문서 업데이트가 더 적합하면 새 문서를 만들지 않는다.

---

# PM Message

문서 수가 많은 프로젝트가 좋은 프로젝트는 아니다.

찾기 쉽고,
중복이 없고,
역할이 명확한 문서가 좋은 프로젝트다.

MEATOS는 문서도 코드처럼 리팩터링한다.
