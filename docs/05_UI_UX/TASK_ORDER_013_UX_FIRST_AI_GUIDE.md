# TASK_ORDER_013_UX_FIRST_AI_GUIDE.md

# 목적

OCR 기능은 강력하지만 사용자는 복잡함을 느끼면 안 된다. 이번 Sprint의
목표는 **AI를 숨기고 업무를 드러내는 UX**를 만드는 것이다.

## 핵심 원칙

-   사용자는 버튼 하나만 누른다.
-   AI는 뒤에서 자동으로 동작한다.
-   실패 시에도 해결 방법을 자연어로 안내한다.
-   전문가 기능은 '고급 보기'에만 배치한다.

## 구현 순서

### STEP 1. 사진 촬영

-   거래명세서 촬영
-   자동 기울기 보정
-   자동 여백 제거
-   자동 해상도 검사

### STEP 2. AI 자동 분석

사용자에게는 진행 상태만 표시 - 사진 확인중 - 거래명세서 분석중 - 품목
정리중 - 재고 반영 준비중

### STEP 3. 결과 확인

기본 화면에는 아래만 표시 - 공급사 - 거래일 - 품목 수 - 총 금액 - \[재고
반영\]

### STEP 4. 추가 기능(접기)

'AI 분석 보기' - OCR 신뢰도 - 인식 실패 영역 - 재촬영 권장 - 템플릿 학습
상태

## AI 자동 동작

-   공급사 자동 인식
-   상품명 표준화
-   동일 거래 중복 검사
-   OCR Failure Learning
-   Supplier Template Learning

## UI 목표

사용자는 '사진 찍고 확인 버튼만 누르면 끝'이라고 느껴야 한다.

## 완료 기준

-   메인 화면 5초 내 이해 가능
-   초보 사용자 설명 없이 사용 가능
-   AI 기능은 숨겨져 있으나 항상 동작
