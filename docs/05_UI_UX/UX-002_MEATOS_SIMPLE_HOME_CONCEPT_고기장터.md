# UX-002_MEATOS_SIMPLE_HOME_CONCEPT.md

# 고기장터(Home UX Concept)

## 서비스 철학

**"고기장터는 ERP가 아닙니다."**

정육점·식당 사장님이 가장 쉽고 빠르게 사용하는 **AI 업무비서**를 목표로
합니다.

> 할아버지도, 할머니도, 초보 사장님도 **1분 안에 사용할 수 있어야
> 합니다.**

------------------------------------------------------------------------

# 상단 브랜드

# 고기장터

*Powered by Eco SmartPD · MEATOS*

------------------------------------------------------------------------

# 메인 메뉴는 4개만

## ① 입력

-   거래명세서 촬영
-   사진 업로드
-   AI 자동 인식
-   입고 등록
-   재고 자동 반영

> 가장 많이 사용하는 화면

------------------------------------------------------------------------

## ② 재고

-   현재 재고
-   부족 품목
-   유통기한
-   입출고 이력

------------------------------------------------------------------------

## ③ 매출

사용자가 가장 자주 보는 화면

-   오늘 매출
-   이번 주
-   이번 달
-   순이익(추후)
-   인기상품
-   재주문 예상

------------------------------------------------------------------------

## ④ 더보기

-   공급사 관리
-   OCR 상태
-   AI 학습
-   사용자 관리
-   백업
-   환경설정
-   도움말

전문 기능은 모두 이곳에 배치합니다.

------------------------------------------------------------------------

# UX 원칙

-   메인 버튼은 4개만
-   글씨는 크게
-   버튼은 크게
-   AI는 뒤에서 자동 동작
-   사용자는 사진만 찍으면 끝

------------------------------------------------------------------------

# 홈 카드

-   💰 오늘 매출
-   📦 현재 재고
-   ⚠️ 부족 품목

------------------------------------------------------------------------

# 핵심 철학

사용자가 보는 것은

**사진 찍기 → 확인 → 완료**

뿐이어야 합니다.

AI는 보이지 않아야 하고, 업무만 보여야 합니다.

------------------------------------------------------------------------

# 목표

"고기장터"는 복잡한 ERP가 아니라

**정육점 사장님의 계산대 옆 AI 비서**가 되는 것을 목표로 합니다.
