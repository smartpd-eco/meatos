# PM 의견

Codex의 피드백을 반영하는 것은 중요하다.

하지만 프로젝트의 방향은 PM이 유지해야 한다.

즉,

- Codex는 구현을 제안한다.
- PM은 우선순위를 결정한다.
- Peter는 전체 아키텍처를 유지한다.

프로젝트는 이 순서로 운영한다.
