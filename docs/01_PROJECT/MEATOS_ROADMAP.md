# 목적

본 문서는 MEATOS의 개발 순서를 정의한다.

좋은 아이디어가 생겨도 Roadmap을 임의로 변경하지 않는다.
변경이 필요한 경우 PM 회고 후 반영한다.

---

# PHASE 1 : Product Foundation

목표
- Product Master 구축
- Product Dictionary 구축
- Supplier Master 구축
- Alias 구조 구축

완료 기준
- 상품 등록 가능
- 검색 가능
- Alias 등록 가능

---

# PHASE 2 : Inventory Foundation

목표
- 입고
- 출고
- 재고
- 재고원장
- 재고이력

완료 기준
- 재고 증감이 모두 기록된다.

---

# PHASE 3 : AI Inbound

목표
- 거래명세서 OCR
- 상품 자동 치환
- 사용자 수정
- Alias Memory 저장

완료 기준
- 사람이 수정한 결과가 다음부터 자동 반영된다.

---

# PHASE 4 : POS Integration

목표
- POS Adapter
- 판매내역 수집
- 자동 출고
- 재고 차감

완료 기준
- POS 판매가 재고에 반영된다.

---

# PHASE 5 : AI SCM

목표
- AI 발주 추천
- 공급사 발주
- 납기 예측
- 재고 부족 예측

완료 기준
- AI가 발주 후보를 추천한다.

---

# PHASE 6 : Knowledge Platform

목표
- 축산물이력 연계
- 도축증명서 연계
- 정부 API 연계
- 상품 지식 확장

완료 기준
- 상품 하나로 모든 관련 정보를 조회할 수 있다.

---

# PM Rule

우리는 기능을 많이 만드는 프로젝트가 아니다.

작은 Sprint를 반복하여
오랫동안 유지 가능한 플랫폼을 만든다.
