# 왜 서두르는가

정부와 공공기관도 AI 기반 축산 유통 플랫폼을 추진하고 있다.

그러나 MEATOS의 경쟁력은 정부보다 먼저 만드는 것이 아니라
현장에서 실제 사용하는 데이터를 더 잘 이해하는 것이다.

---

# 우리가 절대 경쟁하지 않는 것

- 정부 표준
- 법령
- 공공 데이터

정부는 기준(Standard)을 만든다.

---

# 우리가 반드시 이겨야 하는 것

- 거래명세서 이해
- 상품명 치환
- 정육점 언어
- 공급처별 Alias
- Learning Database

이 영역은 현장 데이터가 많을수록 강해진다.

---

# 현재 우선순위

1. Product Master
2. Product Dictionary
3. Alias Engine
4. Review Queue
5. Learning Engine
6. Inventory
7. OCR
8. POS

순서를 바꾸지 않는다.
