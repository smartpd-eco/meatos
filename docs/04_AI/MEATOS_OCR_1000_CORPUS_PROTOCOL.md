# MEATOS OCR 1,000건 평가 코퍼스 운영 기준

## 목적

2015~2026년 축산물 거래 문서의 양식 다양성, 촬영 훼손, 숫자와 이력번호
인식 성능을 1,000건 단위로 반복 검증한다. 이 코퍼스는 OCR 모델의 학습량을
부풀리는 용도가 아니라, 신규 문서에서 정확도와 처리 시간을 재현 가능하게
측정하는 독립 평가 세트다.

## 법적·보안 원칙

공개 웹 문서도 저작권과 개인정보 보호 대상일 수 있다. 검색엔진에서 발견한
이미지는 기본적으로 구조 조사만 하며, 권리와 개인정보 처리가 확인되지 않은
원본은 내려받아 학습하거나 제품에 포함하지 않는다.

실제 문서가 평가 세트에 들어오려면 다음 조건을 모두 충족해야 한다.

1. 제공자 동의 또는 재사용 근거 확인
2. 사업자번호, 전화번호, 주소, 계좌, 서명 등 개인정보·영업정보 비식별 처리
3. 원본과 비식별본의 해시 기록
4. 사람이 검증한 정답지 작성
5. 보존 만료일과 폐기 로그 지정
6. 학습 세트와 평가 세트 분리

## 1,000건 표본 설계

문서군은 도매 거래명세서, 정육점·식당 납품서, 수입 유통 문서, 도축검사증명서,
등급판정확인서, 이력관리 문서, ERP 출력물, 먹지·수기 문서로 나눈다. 축종은
국내 돼지·한우·육우, 수입 소·돼지, 닭·오리, 혼합 품목으로 나눈다. 화질은
정상, 기울기·원근, 그림자·반사, 저해상도·블러, 흐린 먹지·격자, 접힘·가림,
다페이지로 나눈다.

1,000건에서 단순무작위 비율 추정의 최대 95% 표본오차는 약 ±3.10%p다. 다만
같은 원본의 변형본은 독립 표본이 아니므로 동일 문서군으로 묶어 계산하고,
공급사·양식 단위 교차검증을 별도로 수행한다.

## 정확도 판정

- 수량·단가·공급가·세액·금액·이력번호/수입번호: 완전일치만 정답
- 상품명: 문자 정확도와 표준상품 Top-1/Top-5를 분리 측정
- 표 구조: 필수 열 복원율과 행 분리 정확도 측정
- 훼손으로 읽을 수 없는 값: 오답 보정 금지, 공란과 `REVIEW_REQUIRED`
- 숫자 관계가 맞지 않음: 자동 반영 금지
- 처리 시간: warm-up과 cold start를 분리하고 p50/p95를 기록

## 폐기

임시 원본은 `tmp/ocr-corpus-1000/raw`에 격리하고 Git, 로그, 배포 산출물에서
제외한다. 프로젝트 종료 또는 개별 만료일 도래 시 원본과 파생 crop을 폐기하고
해시, 출처, 동의 근거, 집계 성능, 폐기 일시만 보존한다. 폐기는 자동 실행 전에
PM 승인을 받아야 하며 삭제 결과를 감사 로그로 남긴다.

## 현재 상태

현재 승인 실데이터는 1건, MEATOS 소유 합성 문서는 24건이다. 웹 조사 자료는
구조 참고용이며 1,000건 성능 수치에 포함하지 않는다. 따라서 현재 결과는 개발
중간 측정치이고, 1,000건 검증 완료 결과로 표시하면 안 된다.
