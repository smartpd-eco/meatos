# 정육비서(MEATOS) 리비전 기록

## Rev 1.2 — 돈 먼저 (2026-10-19~, 현재 개발 버전)

**기조:** 정육점 사장님이 가장 궁금한 것은 재고보다 *돈*이다.
"오늘 얼마 팔았나 / 카드 대금은 언제 얼마 들어오나 / 이번 달 얼마 남았나"를 먼저 보여주고,
재고는 뒤에서 저절로 쌓이게 둔다.

쉽게 만드는 3원칙
1. **품목 등록 없이 매출부터** — 저울 라벨 바코드의 금액으로 즉시 매출 기록.
   품목은 나중에 한 번만 지정하면 지난 판매까지 자동 반영(재고도 소급 차감).
2. **기초재고 없이 시작** — 재고가 부족해도 판매를 거부하지 않는다. 재고는 0에서 시작해 다음 입고부터 쌓인다.
3. **사장님은 앱을 안 열어도** — "오늘의 돈" 한 화면 + 매일 아침 문자 브리핑(발송사 연결 후 켬).

변경 파일
- DB: `supabase/migrations/202610190001_rev12_money_first.sql`
  - `record_pos_sale_agent`(POS 에이전트), `record_web_scan_sale`(웹 판매 스캔) — 매출+재고 한 번에 저장
  - 품목 지정 시 소급 반영 트리거, `record_manual_sale` 재고부족 차단 해제
  - `get_money_brief`(오늘의 돈), `money_brief_subscription`(알림 구독)
- Edge Function: `supabase/functions/daily-brief` (매일 아침 문자 — 기본은 발송 안 하는 안전 모드)
- 화면: `brief.html`(신규), `sell.html`, `connect.html`, `sales.html`, `header.js`(메뉴 순서), `settings.html`, `privacy.html`
