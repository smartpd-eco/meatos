현장 검증 설치본은 기존 POS를 수정하지 않고 키보드 웨지 입력만 관찰합니다. 품목·중량·금액을 비교하되 매출과 재고는 변경하지 않습니다.

사장님이 매일 입력하는 항목이 아닙니다. 설치할 때 쿠팡이츠 전표 출력과 저울 라벨 출력의 수신 전용 COM 포트를 한 번 연결합니다.
안전 기본값: POS와 쿠팡이츠 모두 현장 검증 모드입니다. 입력·주문·라벨 매칭만 확인하며 재고와 매출은 변경하지 않습니다.
3번 해결하기 · 재고 상품 바코드 연결
설치 전 기업·재고·상품 매핑을 자동 점검합니다.

설치 방법

  1. 재고가 있는 테스트 품목 3개에 실제 바코드를 먼저 연결합니다.
  2. 이 화면 위쪽의 빨간 Windows 현장 검증 설치 프로그램 받기 버튼을 누릅니다.
  3. 다운로드한 파일을 더블클릭합니다. 별도 AutoHotkey 설치나 설정 입력은 없습니다.
  4. Windows SmartScreen이 표시되면 추가 정보 → 실행을 선택합니다. 정식 인증서 적용 전 파일럿 단계 안내입니다.
  5. 설치 완료 메시지와 작업표시줄 트레이의 MEATOS 아이콘을 확인합니다. Windows 로그인 시 자동 실행됩니다.

테스트 절차와 판정 기준

① 재고 확인판매할 품목의 현재고가 0보다 커야 합니다.
② 바코드 연결판매 스캔에서 실제 라벨을 1회 스캔해 재고 품목과 연결합니다.
③ POS 동시 확인메모장에서 13자리 코드+Enter가 입력되는지 확인한 뒤 POS 판매화면에서 같은 라벨을 스캔합니다.
④ 결과 비교아래 관찰 건의 품목·중량·금액을 POS 판매 상세와 비교합니다. 매출·재고 값은 변하지 않아야 합니다.
중요: 키보드 웨지는 스캔과 결제 완료를 구분하지 못합니다. 정상 판매 3건 외에 결제 전 취소 1건·결제 후 반품 1건을 반드시 재현하고, POS 판매 상세 화면 또는 내보내기 파일을 확보해야 운영 전환을 판단할 수 있습니다.
선행조건: Windows 10/11, USB HID 키보드형 스캐너, 인터넷 HTTPS 접속, 승인된 기업 계정과 기본매장, 판매 가능한 재고, 테스트 바코드 매핑 3건. POS 원본 프로그램·DB에는 쓰지 않습니다.
