🔗 자동 판매연동

계산대 바코드 스캔을 MEATOS와 연동합니다. 스캔하는 순간 재고 자동 출고 + 매출 자동 기록.
로그인 후 이용하세요
⬇️ 내 매장 연동 에이전트 다운로드
다운로드되는 프로그램에는 사장님 매장 정보가 이미 연결되어 있습니다. 설정 입력 필요 없음.
로그인해야 매장에 연결된 에이전트를 받을 수 있습니다. 로그인 →

설치 방법 (1회만)

  1. AutoHotkey v2 설치 → autohotkey.com 열기
  2. 위 버튼으로 받은 meatos-scan-agent.ahk 를 더블클릭 실행 (트레이에 아이콘 표시)
  3. MEATOS 판매 스캔에서 품목 바코드를 1회 등록 → 판매 스캔 열기
  4. 이제 계산대에서 스캔하면 재고·매출 자동 반영 (아래에서 실시간 확인)
부팅 시 자동 실행하려면: .ahk 바로가기를 shell:startup 폴더에 넣으세요. (다음 업데이트에서 설치형 .exe 제공 예정)
